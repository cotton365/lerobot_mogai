### 将jaka和mycobot接入lerobot项目
1. 关键文件在src/lerobot/robots/里面可以找到jaka的从臂代码和mycobot的主臂从臂代码
2. 在so101_test下是写好的遥操脚本，校准等前置任务脚本也有
3. 注意jaka使用TCP/IP协议，这也是为什么这里使用了脚本而不是接入已有框架
4. jaka原本没有夹爪，夹爪部分，也就是这里的第七个关节没有做映射处理，需要按照自己需求编写
### jaka机械臂特性（官网：https://www.jaka.com/docs/documents/SDK/Python.html）
1. 这里面使用的是伺服模式调用，好处是节省时间，可以随时遥操，不过运动控制需要自己处理
2. 运动控制上使用的是滤波算法，针对加速度和速度上加上了限幅，每次输入的是机械臂位置，最终结果是按照滤波后的速度加速度进行位移
3. jaka默认8ms一个周期，125Hz，但是lerobot默认是60Hz，这里做了兼容性处理，如果想修改频率，可以自己在servo_j函数的形参里面修改step_num，这里默认是1，但是不建议修改，因为可能会导致运动计算上，速度等参数计算有误
4. jaka固件版本使用的是1.7.2，如果有更新的版本，需要自己在jaka_follower的py文件下，将基础的命令进行修改
### mycobot机械臂
1. 这里mycobot的follower是使用的从臂，主臂为自己制作，后续会逐步更新硬件部分
2. 这里面针对于leader制作上参考了so101，但是零件为自己设计，只需要满足与jaka机械臂比例一致即可，但是要保证电机可以正确反映角度变换
3. 这里因为参考了so101，mycobot_leader本身的角度读取和so101大差不差，不过需自己注意镜像问题
4. 协同上，并没有制作特别的保护措施，不过这里考虑到jaka的TCP/IP协议，每次从jaka身上读取位姿会导致很大的延迟，此处每次循环是只从mycobot身上读取位姿，并默认与jaka一致的，需要注意这里两个机械臂必须在启动程序前保持一致的相同姿态，在脚本启动前，会有指令将jaka恢复到默认状态，mycobot一开始就保证与jaka默认姿态一致即可，具体的值是[0, 1.5, 0.01, 1.6, 0.0, 1.5]，位置是robot的jaka机械臂资产文件的jaka_follower.py下
### 补充
1. 数据采集本身其实在这个工作流程就在收集，不过相机需要自己准备
2. 数据的训练部分，需要lerobot本身的训练算法提供，后面将训练好的数据调入jaka下运动需要额外做兼容性处理
